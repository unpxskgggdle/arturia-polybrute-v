## Overview

Arturia PolyBrute V is the software emulation of the hardware PolyBrute analog synthesizer, offering all the sonic power of the flagship hardware in a DAW plugin format.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia PolyBrute V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **PolyBrute Engine** | Same dual-oscillator analog voice architecture as the hardware |
| **Morphee Simulation** | On-screen Morphee 3D controller for expressive parameter sweeps |
| **Full Modulation** | Complete modulation matrix with hundreds of routing options |
| **Preset Compatibility** | Compatible with hardware PolyBrute preset banks and libraries |
